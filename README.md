# IT Service Desk Process Improvement

## Project Overview

This portfolio project demonstrates the application of Business Analysis and Process Improvement techniques to evaluate and redesign an IT Service Desk ticket escalation process.

The objective was to document the current business process, identify operational inefficiencies, define business and functional requirements, and propose an improved future-state workflow that prepares the organization for reporting, automation, and continuous process improvement.

---

# Business Problem

The existing ticket escalation process relied heavily on manual communication, inconsistent routing decisions, and repetitive administrative work.

These manual activities created opportunities for delayed response times, inconsistent escalation practices, limited operational visibility, and increased workload for technical support staff.

---

# Project Objectives

- Document the current ticket escalation process
- Identify process inefficiencies and pain points
- Gather and document business requirements
- Define functional and non-functional requirements
- Design an improved future-state workflow
- Improve reporting readiness
- Identify workflow automation opportunities
- Increase operational visibility

---

# Proposed Solution

The proposed solution introduces a standardized ticket escalation process supported by documented business rules, clearly defined requirements, improved reporting capabilities, and future automation opportunities.

The redesigned process focuses on:

- Standardizing ticket routing
- Improving SLA visibility
- Reducing manual communication
- Increasing reporting accuracy
- Creating a repeatable support workflow
- Preparing the process for future automation initiatives
