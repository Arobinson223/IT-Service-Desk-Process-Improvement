IT Service Desk Process Improvement
Project Overview

This project demonstrates how business analysis techniques can be used to evaluate and improve an IT Service Desk ticket escalation process.

The objective was to reduce manual work, improve escalation consistency, increase reporting visibility, and prepare the workflow for automation using Microsoft technologies.

Business Problem

The existing ticket escalation process depended heavily on manual communication, manual status updates, and inconsistent routing of high-priority incidents.

These manual activities increased administrative effort and limited operational visibility.

Proposed Solution

Design a standardized workflow that:

Standardizes ticket routing
Improves SLA visibility
Supports workflow automation
Improves executive reporting
Creates reusable business documentation
